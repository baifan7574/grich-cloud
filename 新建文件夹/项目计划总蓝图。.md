# GRICH 项目总蓝图 (Master Blueprint)

## 1. 商业本质

- \*\*核心逻辑\*\*：利用 pSEO 技术拦截美国 IP 诉讼流量，为资金冻结卖家提供 $9.9 AI 法律情报报告。

- \*\*核心目标\*\*：实现月收入 $3,000，支持创始人 Michael Bai 的欧洲数字游民计划 [cite: 2025-12-27]。

## 2. 创始人背书 (E-E-A-T)

- \*\*Michael Bai\*\*：16 年职场背景，涵盖法学、心理咨询（国家二级）、教育（校长）、媒体（记者）及实战讲师 [cite: 2025-12-26, 2025-12-28]。

- \*\*要求\*\*：所有生成的网页和报告必须注入上述专家背景，以建立信任并优化 SEO [cite: 2025-12-26]。

## 3. 技术标准

- \*\*基础设施\*\*：Cloudflare Workers/Pages + Supabase (数据库)。

- \*\*动态路由\*\*：必须实现 `[brand]` 动态路径，以承载 5,000+ 个品牌案号页面。

- \*\*备选机制\*\*：首选 Next.js 15，若构建持续失败，强制切换至 Astro 框架。
